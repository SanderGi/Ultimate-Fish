## Corrected-rule live validation — 2026-08-04

Live Unranked play exposed one material rules error that the static fixtures had
not distinguished: a Checker with an available first jump suppresses that
Checker's own quiet moves, but it does **not** force the entire side to move the
Checker. Only an already-started multi-jump is globally forced. The native app
accepted `bishop b9-c8` while `checker d9-b7` was available; Ultimate Fish now
accepts both, while retaining the forced continuation after the first jump. A
dedicated regression position fixes this behavior.

After that correction, the saved 100-point Giant roster completed three fresh
Very Hard CPU games at depth 7 with **3 wins / 0 losses**. The set included a
64-belief hidden-Ghost opening and two forced-checkmate finishes. Three fully
automated Unranked wins are also confirmed with the optimized roster; failed
public-position probes and opponents who did not accept an offer are excluded
from the result count.

The corrected-rule deployment tournament used three generations and four finalists,
alternating colors, and a 10,000-node finalist pass. The conventional
five-Queen roster and the live Giant roster tied at **0.8000** over ten games.
The Giant roster remains the live default because it has the stronger external
validation above; the tie does not justify rebuilding a proven native army.

## Native information-set search checkpoint — 2026-08-04

The former Python plurality/top-three audit and repetition replacement were
removed. The C++ engine now owns the entire common-root decision across the
retained public-information set. It shallow-searches every common action in
every belief, then deep-searches the robust shortlist across eight evenly
spaced representatives while forcing each candidate's worst shallow belief
into its deep sample. An adversarial regression proves that a concrete safe
world takes an exposed Pawn with a continuing attack while the two-world search
rejects that root when another legal world contains the hidden-Ghost recapture.
A second regression
places possible Ghosts adjacent to a winning Queen move and proves that the
engine still captures the real King; no hardcoded material/adjacency filter is
present.
