THE EXPERIMENT

Mapping the simulated brain to moves.

Every choice runs the full 164,587-neuron MaleCNS v1.0 circuit, retaining all 25,563,197 measured directed connections. Eight engineered descriptions of each legal action stimulate sensory cells. A trained linear readout of 2,129 descending and motor cells ranks the actions.

The biological wiring stays fixed. The artificial readout learned from node-limited Ultimate Fish searches. Neural inference and native Ultimate move rules run on this server. The browser displays the game and animations.

Note that this connectome-based computation experiment does not imply that a living fly understands Chess Ultimate. Neuron dynamics and sensory encoding are engineering assumptions. The anatomical body’s flight and hovering are authored animations. Dim points always show the measured anatomy. During computation, recorded full-circuit runs provide the waiting animation; these are not live telemetry from the current move. Once computation finishes, its own activity replay takes over.

We deliberately only allow choosing from pre-determined armies to avoid the possibility of using the fly to cheat (not that it would be good at that lol).
